# kaaroViewer — Platform Vision

Leverage the Open Graph, open knowledge graph, shared memory and local memory of users.

Provide a visual canvas that builds a real-time stream live view — in HTML canvas via Three.js — enriched from public knowledge sources (Wikidata, Wikipedia, GitHub, HN, YouTube, Reddit, npm).

The user continually interacts with voice, text, and clicks on entities and actions in the canvas.
