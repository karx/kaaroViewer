## 2026-06-07 — Dream Loop Triggered (reveals)

**Pattern:** `reveals` rel appeared in edges[] across 3 consecutive Alone-Time runs (aoe-2-redbull, poker-tooling, gig-worker-projects).

**Root Cause:** Encoder writes `reveals` from training memory as semantic proxy for "exposes/demonstrates". But `reveals` is auto-generated by canvas loader at runtime. Having it in edges[] causes duplicate/conflicting edges at render.

**Action Taken:** Promoted `reveals` from warning → error in validator. Added prohibition banner to SOP Step 2b. No renderer change needed (constraint tightening only).

**Signal Quality:** High. Clean 3/3 pattern. Handoff schema captured it unambiguously.

**Learning:** The handoff "What Could Not Be Resolved" section *is* the Dream Loop sensor. It worked.
